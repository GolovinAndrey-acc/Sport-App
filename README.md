# Sport

Личное приложение для тренировок: https://golovinandrey-acc.github.io/Sport-App/

## Как поменять иконку

1. Подготовь картинку **PNG, квадратную**, лучше 1024×1024. Главное держи ближе к центру — телефон может срезать углы.
2. Назови файл **`icon.png`**.
3. Здесь, на GitHub: **Add file → Upload files** → перетащи `icon.png` (старый заменится) → **Commit changes**.

Внутри приложения иконка обновится сама. Иконку на главном экране iPhone и в Dock на Mac
система запоминает при установке — чтобы её поменять, приложение нужно один раз удалить и добавить заново.

### Автоматическая обработка

После загрузки `icon.png` GitHub сам (вкладка **Actions** → «Обработка иконки») за ~1 минуту:
заливает прозрачные места белым, обрезает пустые поля, ставит картинку по центру и делает её 1024×1024.
Исправленный файл сохраняется в репозиторий отдельным коммитом. Цвет фона и отступ можно поменять
в начале файла `.github/scripts/fix_icon.py` (`BG` и `MARGIN`).
