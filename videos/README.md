# Видео к упражнениям

Загружай сюда файлы **.mp4**. Имя файла = id упражнения из `data.js`.
Видео само появится в карточке упражнения (без звука, по кругу).

| Файл | Упражнение | Уровень |
|---|---|---|
| `knee-back-walk.mp4` | Ходьба спиной вперёд на дорожке | Разминка |
| `knee-quad-set.mp4` | Напряжение квадрицепса с задержкой | Лёгкий |
| `knee-tke.mp4` | Разгибание колена с резинкой | Лёгкий |
| `knee-sl-bridge.mp4` | Ягодичный мост на одной ноге | Средний |
| `knee-lat-stepdown.mp4` | Боковые шаги вниз со степа | Средний |
| `knee-sl-box-squat.mp4` | Приседания на одной ноге на тумбу | Продвинутый |
| `knee-sl-leg-ext.mp4` | Разгибание одной ноги в тренажёре | Продвинутый |
